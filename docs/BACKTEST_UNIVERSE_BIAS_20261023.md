# バックテスト ユニバース生存者バイアスの分離測定（2026-10-23）

出典: `docs/BACKTEST_LEAK_REVIEW_20261023.md` C1【高】
目的: 「SPY超過 12.3pp/年」がシグナル効果なのか、銘柄選択（固定ユニバース）効果なのかを実測で切り分ける。
制約遵守: 実注文なし / 外部送信なし / ネットワーク取得なし / 既存コードの変更なし / 測定は読み取りとメモリ上の再構成のみ。
本 doc の数値はすべて本リポジトリの永続 OHLCV と、commit `1374165` を固定展開した `run_backtest`、および SEC 分割カレンダーから得た実測値である。推測は「推測」または「仮定計算」と明記した。

## 0. 結論（先に要点）

1. **ユニバース選定根拠は「2026-09-30 に、評価期間終了後に、現存14銘柄から10銘柄を選んだ」以外に記録がない。**
   `src/yowayowa/backtest_strategies.json` は commit `a795601`（2026-09-30 12:57 JST）で追加され、6戦略すべてが同一の10銘柄
   （AAPL/MSFT/NVDA/GOOGL/AMZN/META/TSLA/JPM/XOM/SPY）を持つ。選定理由はコード・コミットメッセージ・`docs/BACKTEST_REPORT_P3.md` のいずれにも書かれていない。
   選定は評価窓（2021-01-04〜2026-09-28）の終了後であり、結果を見てから銘柄を決められる位置にある（意図の有無は記録がないため断定しない）。
   上場廃止銘柄は**1銘柄も含まれない**（取得リスト `docs/STOCKS.md:82-84` が「現在指定された14銘柄だけであり、過去時点のS&P 500構成銘柄ではない」と明記）。
2. **超過の内訳（実測、2021-01-04〜2026-09-28、1,440セッション、分割補正後）**

   | 効果 | 実測値 | 意味 |
   |---|---:|---|
   | 現行ユニバース等加重 B&H − SPY | **+12.17pp/年**（25.79% vs 13.63%） | 銘柄選択（ユニバース）効果。**これが報告超過のほぼ全部** |
   | 分割補正 − 生価格（同一ユニバース） | **+9.26pp/年**（25.79% vs 16.53%） | 本doc実測（SEC分割カレンダー7件による後方補正）。ユニバース効果とは独立に乗る |
   | シグナル効果（同一ユニバース・分割補正後、戦略 − 等加重B&H） | momentum **−5.55pp** / low-vol **−8.94pp** / mean-reversion **−8.83pp** / 等加重戦略 **−0.42pp** | 3シグナルとも同一ユニバースの受動保有に**負ける** |

3. **したがって「バックテストの戦略がSPYを上回った」という読み方は成立しない。** 報告CAGR（13.54〜16.84%）は
   SPY 13.63% とほぼ同じで、分割補正すると同一10銘柄の受動等加重（25.79%）に 5.5〜8.9pp 負ける。
   数字の正体は「2026年時点の勝ち銘柄10個を等加重で持ったこと」＋「分割を補正していないこと」。
4. **生存者バイアスそのものの大きさは分離不能。** 上場廃止銘柄の価格がリポジトリに存在しないため、
   「除外された銘柄がいた場合」を実データで測れない。分離できるのは
   (a) 銘柄選択効果の総量、(b) 重み付け方式の寄与、(c) プール拡張への感度、(d) シグナル効果、までである。
5. **採用可否: 現行の戦略CAGR/Sharpe/OOS数値は「生存者バイアス込み・分割未補正」であり、戦略の優劣判断には使えない。**
   使えるのは (i) 同一ユニバース内の相対比較（等加重B&Hを基準にした差分）、(ii) 分割補正後の同一条件比較、のみ。

## 2. 測定条件

- 入力: `data/stock-ohlcv`（alpaca, USD, `adjustment=raw`）。**ネットワーク取得なし**。
- 評価窓: 2021-01-04〜2026-09-28（`run_backtests_p3.py` の既定窓と同一、1,440セッション、5.714年）。
  C1 レビュー本文の 2026-10-20 窓とは終端が違うため、数値は 25.86%→25.79%、13.56%→13.63%、+12.3pp→+12.17pp と僅かに異なる（同一現象）。
- 分割補正: **`data/fundamentals/pbr/split-calendar.json`（SEC 確定カレンダー）を正**とし、各イベント日より前の価格を比率で除算（後方補正）。
  収録7件: AAPL 2020-08-31 4:1（0000320193-20-000096）、TSLA 2020-08-31 5:1（0001564590-20-047486）、
  NVDA 2021-07-20 4:1（0001045810-21-000131）、AMZN 2022-06-06 20:1（0001018724-22-000019）、
  GOOGL 2022-07-18 20:1（0001652044-22-000071）、TSLA 2022-08-25 3:1（0000950170-22-019867）、
  NVDA 2024-06-10 10:1（0001045810-24-000264）。**窓内イベントは5件**（2020年の2件は窓外）。
  このカレンダーは `src/yowayowa/sec_pbr.py` の `split_calendar()` が、SEC の ratio タグ
  （`us-gaap:StockholdersEquityNoteStockSplitConversionRatio1`）と価格不連続を突き合わせて作る**遡及的な再構成**であり、
  事前のコーポレートアクション検知ではない（同関数 docstring が明記）。価格比検出器（open(t)/close(t−1)<0.6・整数比・残差2%未満）は
  **突合のみ**に使い、入力の作成には使っていない（突合結果は §2-2）。
  配当・スピンオフは未補正。META 2022-02-03 の −26.4% は比 0.757 で分割ではない（実イベントで、検出器も拾わない）。
- CAGR: 252営業日年率（セッション数/252 を年数とする）。Sharpe は無リスク金利0（エンジンと同定義）。
- 戦略エンジン: **commit `1374165` の `src` を `git archive` で固定展開したもの**（`<artifacts>/engine_1374165/src`、
  `services/backtest.py` の sha256 `b15c1096…7e8d0`）を使用。この版は分割補正処理を持たない（grep 0件）ため、補正は入力側だけで行う。
  commission 10bps + slippage 5bps = 片道15bps、`next_open`、月次、IID ブートストラップは今回0回。
  実装検証: 生価格・現行10銘柄の実行結果は `backtest_results_p3.json` と完全一致（momentum 13.72 / low-vol 13.54 / mean-rev 16.84 / 等加重 16.27、Sharpe 0.616 / 0.773 / 0.722 / 0.735）。**測定系が本番エンジンと同一であることはこれで確認済み。**
- PIT近似: 窓**前**の情報だけを使う規則として「2020年の日中出来高（close×volume）中央値 上位10銘柄」を採用。
  それでも母集団が現存14銘柄である以上、**生存者バイアスは残る**。

## 4. シグナル効果とユニバース効果の分離（エンジン実行・実測）

同一エンジン・同一コストで、`raw` と `split_adj` の両方を回した。**シグナル効果 = 戦略CAGR − 同一ユニバース等加重B&H CAGR**（分割補正後）。

| ユニバース | 価格 | 等加重B&H | momentum_12_1 | low_volatility | mean_reversion_20 | equal_weight戦略 |
|---|---|---:|---:|---:|---:|---:|
| 現行10 | raw | 16.53% | 13.72% (−2.81) | 13.54% (−2.99) | 16.84% (+0.31) | 16.27% (−0.26) |
| **現行10** | **split_adj** | **25.79%** | **20.24% (−5.55)** | **16.85% (−8.94)** | **16.96% (−8.83)** | **25.37% (−0.42)** |
| PIT近似10 | raw | 13.51% | 6.95% (−6.56) | 15.19% (+1.68) | 17.22% (+3.71) | 13.21% (−0.30) |
| PIT近似10 | split_adj | 22.53% | 18.02% (−4.51) | 15.19% (−7.34) | 17.34% (−5.19) | 22.02% (−0.51) |
| 全14 | raw | 14.92% | 11.19% (−3.73) | 8.56% (−6.36) | 16.22% (+1.30) | 14.57% (−0.35) |
| 全14 | split_adj | 21.30% | 21.79% (**+0.49**) | 8.56% (−12.74) | 16.60% (−4.70) | 20.84% (−0.46) |

（括弧内は同じ行の等加重B&H との差。等加重B&Hは理論値（日次等加重・コスト0）で、`u_bias_bh.py` / `u_bias_fill.py` の出力。
等加重戦略はコストぶんだけ下回る＝サニティチェック。現行10 raw の差 −0.26pp は、年間 turnover 0.96x×15bps＝0.14pp のコストと、
B&H を日次リバランス・戦略を月次リバランスで測っている差の合計であり、同じ桁に収まっている。）

要点:
- **分割補正すると、3シグナルすべてが同一ユニバースの受動保有に 5.5〜8.9pp/年 負ける。** 等加重戦略の −0.42pp はほぼコストのみで、ロジックの妥当性確認になる。
- **シグナルの符号はユニバースで反転する**（momentum: 現行10 −5.55pp / 全14 +0.49pp / PIT近似10 −4.51pp）。安定した edge ではない。
- low_volatility は全14プールで −12.74pp と最悪。保有先を実測すると SPY 69回・PG 66回・JNJ 62回・QQQ 45回・IWM 39回で、
  **低リターンのディフェンシブ銘柄（PG +1.38%、JNJ +10.15%、IWM +6.68%）に寄る構造**がそのまま劣後になっている（決定的な選択なので分散しない）。
- 分割補正の効果は戦略側にも及ぶ（momentum +6.52pp、low-vol +3.31pp、等加重 +9.10pp、mean-reversion +0.12pp）。**分割補正の効果とユニバース効果は独立に乗る**（両方効いている）。
- OOS は raw/adj で**同一値**（momentum −6.60%、low-vol +35.37%、mean-rev +16.73%、等加重 +20.00%）。
  OOS 開始が2025-01〜2026-01で、窓内の分割イベント（最終 2024-06-10）より後だからである。
  **したがって「OOSでmomentumが負けた」は分割補正の産物ではない**（C4 側の論点）。

### 4-1. 除外銘柄を仮想的に足した場合の感度（**仮定計算、実データではない**）

上場廃止銘柄の実績は存在しないため、これは「k銘柄を追加したら gap がどう動くか」の機械的感度にすぎない。

| 追加銘柄の仮定CAGR | k=1 | k=2 | k=3 | k=4 | k=5 |
|---|---:|---:|---:|---:|---:|
| 0%（全損） | +9.86 | +7.92 | +6.27 | +4.86 | +3.63 |
| +1.38%（=PG、現存最下位） | +10.01 | +8.20 | +6.65 | +5.32 | +4.17 |

含意: 除外銘柄が「指数並み（+13.63%）」だったと仮定しても、2銘柄で 10.5pp、5銘柄で 8.7pp 残る。
一方「全損級」なら 2銘柄で 7.9pp まで縮む。**この仮定の置き方で結論が変わるため、実データなしに生存者バイアス分を数値で断定してはならない。**

## 5. 分離できる / できないの結論

**分離できた（実測）**
- 銘柄選択（ユニバース）効果の総量: **+12.17pp/年**（分割補正後、同一期間）。
- 重み付け方式の寄与: 等加重 → 2020年流動性加重で **12.17 → 4.78pp**（−7.4pp）。
- プール拡張への感度: 現存14銘柄へ広げて **7.67pp**（−4.5pp）。1銘柄（NVDA）除外で **7.5pp**。
- 分割補正の寄与: 同一ユニバース・同一固定エンジンで **+9.26pp/年**（SEC カレンダー7件、本 doc 実測）。C2 の採否とは独立。
- シグナル効果: 同一ユニバース・分割補正後で **−5.55 / −8.94 / −8.83pp**（3シグナルとも負）。ユニバースを変えると符号が反転する。

**分離できない**
- **生存者バイアスそのものの量（上場廃止・M&A・指数除外銘柄の不在分）。** 理由はデータ不在:
  `data/stock-ohlcv` は現存14銘柄のみ、`data/stock-ohlcv.bak` は3銘柄、`data/private-acquisition/alpha-vantage` は `usage.json` のみ。
  `docs/STOCKS.md:82-84` が「過去時点のS&P 500構成銘柄ではない」と明記しており、これは実装の欠陥ではなく取得範囲の宣言どおり。
- **point-in-time 構成銘柄による再現。** 本 doc の「PIT近似」（行3/5/6）は*選定規則*を窓前情報に限定しただけで、
  *母集団*は現存14銘柄のままである。真の PIT ユニバースではない。
- 上場廃止リターン（delisting return）のモデル化。エンジンにもデータにも存在しない。

## 7. 分離に必要な追加データ（優先順）
