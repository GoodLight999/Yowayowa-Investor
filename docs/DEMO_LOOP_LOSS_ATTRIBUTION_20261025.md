### 案2: 逆ボラ配分 — **エンジン変更要（`weighting` 1フィールドでは効かない）**

- **実装経路の実測**: `crypto_trend_dual_ma` は `src/yowayowa/services/backtest.py:421-433` で **early return** する。汎用の `weighting == "inverse_volatility"` 分岐（`:517-529`）には到達せず、重みは `:432` の `weight = 1 / len(active)` で確定して返る。`:811-816` は warmup の下限調整のみで、しかも `crypto_trend_dual_ma` はその**除外集合**に入っている（＝このシグナルは設計上も汎用の重み付け対象外）。
