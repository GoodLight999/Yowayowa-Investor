# S-07 X3 runner contract (acceptance draft)

- Entry: `python -m yowayowa.hl_exec.s07_forward.runner`. Required arguments: `--day` (ISO UTC day), `--market-json`, `--out`, `--data-dir`, `--account`, `--fills-json`, `--funding-json`, `--state-json`, `--orders-json`. Inputs are read-only; output is an isolated directory. The stopped legacy script, production ledger and cron remain untouched.
- Default is dry-run. `--enable-order-path` explicitly requests the order path; no real sender, signer, credentials or broker adapter is connected. Without an injected test sender, even this flag fails closed. CLI never injects a sender. Exit 0 means successful dry-run or already recorded; invalid inputs, failed X1 and blocked submission exit nonzero (2); argparse errors exit 2.
- Before deciding, writing the decision ledger or invoking any order path, call X1 `yowayowa.hl_exec.s07_authenticity.runner.run` with `out_dir` isolated from `data_dir`, `offline=True`, and the supplied account and four snapshot paths. Require both `exit_code == 0` and `result.verdict == "PASS"`; any other result aborts.
- Output `ledger.jsonl` is UTF-8 JSON Lines, append-only, one JSON object per UTC `day`, including `day` and `signal`. A repeated day adds no line and makes no duplicate order. Report is per-day JSON under `reports/`.
- Test-only Python interface: `run_day(..., enable_order_path=False, sender=None, order_status=...)`. The sender is an injected mock, never a real implementation. Unknown, pending, missing or unverified order state cannot be resent. A mock resend is permitted only after independently confirmed cancellation for the matching order and reconciliation of remaining quantity. The status values `unknown` and `cancel_confirmed` in initial acceptance tests are synthetic; implementation must not treat an unverified caller string as real cancellation evidence.
- Tests use synthetic inputs, temporary output, mocks, and blocked network. RED from an absent sender interface means the prototype has not met the contract; it does not establish that other safety properties have passed end-to-end.
