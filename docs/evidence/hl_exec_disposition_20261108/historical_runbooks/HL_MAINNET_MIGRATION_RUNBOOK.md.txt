## 0. 専門用語の言い換え（はじめに）

| 専門用語 | わかりやすい言い換え | 備考 |
|---|---|---|
| **USDC** | 米ドルと同じ価値を持つデジタル通貨（1 USDC ≒ 1 米ドル ≒ 約150円） | 価格変動がなく、1ドル=1ドルで安定しています |
| **Arbitrum One** | 手数料が数十円と格安で、数秒で送金できるイーサリアム系の送金ネットワーク | 取引所から出金する際の「ネットワーク選択」で選びます |
| **Deposit（デポジット）** | 取引所（Hyperliquid）の口座にお金を預け入れること | 銀行の「預入れ」と同じです |
| **API Agent（エージェント）** | ボット専用の「取引代理人」 | **出金権限を持たない**ため、万一ボット側が事故を起こしても**資金を外部に持ち出せない極めて安全な仕組み**です |
| **approveAgent** | 取引代理人に「私の代わりに売買注文を出してよい」と許可のサイン（電子署名）をすること | ガス代（送金手数料）は不要で、ウォレットのサインのみで完了します |

## 2. 初回入金額の推奨と数値根拠

### 【結論】
- **推奨額: 初回 100 USD（約15,000円）**
- **余裕を見る場合: 200 USD（約30,000円）**
- **初期検証に 1,000 USD（約15万円）以上は一切不要**です。

### 【数値による根拠】
1. **取引所の最小注文サイズ（Min Notional）**:
   - Hyperliquid の公式仕様上、全パーペチュアルで**1注文の最小額は 10.0 USD** です。
2. **当システムのリスク規律（`margin_cap_pct = 10%`）**:
   - 安全運用のため、「1ポジションに割り当てる証拠金の上限は口座資金（Equity）の 10%」と定めています。
3. **口座資金ごとの比較**:
   - **Equity 100 USD の場合（推奨）**:
     - 1ポジションの証拠金上限 = $100 \times 10\% = \mathbf{10.00\text{ USD}}$
     - 最小発注額（10 USD）とジャストで噛み合い、1倍〜3倍程度の低レバレッジで最小ロット（0.0002 BTC 等）を無理なく置くことができます。
     - システムの日次損失停止（$-2\%$ = $-2.0\text{ USD}$）および最大累積DD停止（$-4\%$ = $-4.0\text{ USD}$）が正常に働き、**1回の最大損失は概ね 10 USD（約1,500円）以下**に確実に抑えられます。
   - **Equity 50 USD の場合（非推奨）**:
     - 1ポジションの証拠金上限 = $50 \times 10\% = 5.00\text{ USD}$
     - 取引所の最小発注額（10 USD）を置くにはレバレッジを2倍以上に引き上げる必要があり、規律上の上限枠（5 USD）を突破してしまうため、設計と噛み合わず運用が極めて窮屈になります。
   - **Equity 200 USD の場合（余裕版）**:
     - 1ポジションの証拠金上限 = 20.00 USD。
     - CIO基本設計書（`CIO_HL_EXECUTION_TRACK_PLAN.md`）のマイクロ実弾枠上限であり、よりバッファを持たせたい場合に最適です。

## 3. マスター向け作業手順（①〜⑤・所要約3〜5分）

ブラウザ（MetaMask等のウォレットが入ったPC端末）で以下の手順通りに進めてください。

```
[全体の流れ]
① USDC を Arbitrum に用意
   ↓
② app.hyperliquid.xyz で Deposit → 本番ウォレットへ送金
   ↓
③ 画面上で残高の反映を確認（入金額になるまで待機）
   ↓
④ app.hyperliquid.xyz/API でエージェントを承認（Connect → 署名）
   ↓
⑤ 「完了」と一言チャットへ連絡 → システム側で機械照会して報告
```

---

### ① USDC を Arbitrum に用意する
- 国内外の暗号資産取引所（例: Bybit, Bitbank, OKX等）または外部ウォレットから、マスターのウォレット（MetaMask等）宛に **USDC** を送金します。
- **送金ネットワーク**: 必ず **「Arbitrum One」** を選択してください（Ethereum メインネットを選ぶと手数料が高額になります）。
- ※クレジットカード等で Arbitrum One の USDC を直接購入できるウォレットをお使いの場合は、それでも構いません。
- 金額目安: **100 USDC**（約1.5万円）〜 **200 USDC**（約3万円）。
- ※少額のガス代（ETH）が数十円〜100円程度ウォレットに入っている必要があります。

---

### ② https://app.hyperliquid.xyz で入金（Deposit）＆送金

1. ブラウザで **`https://app.hyperliquid.xyz`** にアクセスします。
   - ※必ずドメインが `app.hyperliquid.xyz` であることを確認してください（テストネット `app.hyperliquid-testnet.xyz` ではありません）。
2. 画面右上の **「Connect」** をクリックし、マスターのウォレットを接続します。
3. 画面右上またはポートフォリオ画面にある緑色の **「Deposit」** ボタンを押します。
4. 入金画面でネットワーク「Arbitrum」と金額（例: `100` USDC）を指定し、ウォレットの承認ポップアップを承認します（通常数十秒で Hyperliquid 残高に反映されます）。
5. 続いて、画面下の残高欄または Trade 画面の Spot 残高横にある **「Send」** ボタンを押します。
6. 送金先アドレス（Destination）に、**本番用ウォレットアドレス** を貼り付けます:
   ```
   0x4c95c6153bc98f225a2cb6c625911a6403767f98
   ```
7. 金額に `100` USDC を入力し、**「Send」**（確認画面で I confirm）を押してウォレットで署名承認します。
   - ※Hyperliquid 内の L1 送金（usdSend）は **手数料ゼロ（ガス代無料）・即時完了** です。

> **【運用補足: マスターのウォレットを直接運用口座とする場合】**
> もし「システム側ウォレットへ送金せず、マスター自身のウォレット口座のままボットに運用させたい」場合は、手順5〜7の「Send」をスキップしてご自身の口座に 100 USDC を置いたままでも構いません。その場合は後述の手順⑤でマスターのアドレスをお知らせください。

---

### ③ 入金確認（画面の残高が入金額になるまで待つ）

- 画面上部または Portfolio の「Account Value」が **`$100.00`**（または入金額）になっていることを確認します。
- 送金・入金は通常 10秒〜1分程度で反映されます。

### ④ https://app.hyperliquid.xyz/API でエージェントを承認する

1. ブラウザで **`https://app.hyperliquid.xyz/API`** を開きます。
2. 画面中央のフォームに以下の通り入力します:

```
+-----------------------------------------------------------------------------------+
|  API                                                                              |
|  API wallets (also known as agent wallets) can perform actions on behalf of...    |
|                                                                                   |
|  [ API Wallet Name                     ]  [ API Wallet Address        ] [Connect] |
|  yowayowa-exec-main                       0xa561fa36e962f6b4c59...                |
|                                                     Generate                      |
+-----------------------------------------------------------------------------------+
```

- **`API Wallet Name`**:
  ```
  yowayowa-exec-main
  ```
- **`API Wallet Address`**:
  ```
  0xa561fa36e962f6b4c59f87b5d94f034a74c8280b
  ```
- ⚠ **重要警告**: アドレス入力欄のすぐ下にある小さな青文字の **`Generate` は絶対に押さないでください**。
  （ブラウザ側で別の新しい鍵を自動生成してしまうためです。今回はシステム側で生成した鍵のアドレスをそのまま貼り付けます）
3. 入力欄の右端にある **「Connect」** ボタンをクリックします。
4. ウォレット（MetaMask等）のポップアップ画面に「approveAgent」の署名要求が出ますので、内容を確認して **「署名」または「承認」** をクリックします。
   - ※この操作はブロックチェーンのガス代はかかりません（無料の電子署名です）。
5. 画面下の一覧テーブルに `yowayowa-exec-main` の行が追加されれば**登録完了**です！

マスターからの連絡受領後、以下のコマンドで取引所 L1 状態を完全に実測します。
（秘密鍵不要・公開 API のみ使用・改ざん不能な実測値）

### 実行コマンド（コピペ可能）:

```bash
# 専用検証スクリプトによる一括検証
python3 /root/current-work/yowayowa-investor/scripts/verify_mainnet_state.py
```

または curl コマンドによる直接照会:

```bash
# 1. 口座残高（accountValue）の照会
curl -s -X POST https://api.hyperliquid.xyz/info \
  -H "Content-Type: application/json" \
  -d '{"type":"clearinghouseState","user":"0x4c95c6153bc98f225a2cb6c625911a6403767f98"}' \
  | jq '.marginSummary'

# 2. 承認エージェント一覧の照会
curl -s -X POST https://api.hyperliquid.xyz/info \
  -H "Content-Type: application/json" \
  -d '{"type":"extraAgents","user":"0x4c95c6153bc98f225a2cb6c625911a6403767f98"}' \
  | jq .

# 3. 未約定注文（openOrders）の照会（期待値: []）
curl -s -X POST https://api.hyperliquid.xyz/info \
  -H "Content-Type: application/json" \
  -d '{"type":"openOrders","user":"0x4c95c6153bc98f225a2cb6c625911a6403767f98"}' \
  | jq .
```

### 合格判定基準（受入条件5）:
1. `accountValue`: 入金額（100.0 USD 等）が反映されていること
2. `extraAgents`: 1件登録されており、`address` が `0xa561fa36e962f6b4c59f87b5d94f034a74c8280b`、`name` が `yowayowa-exec-main` であること
3. `openOrders`: `0` 件（空配列 `[]`）であること
4. `assetPositions`: `0` 件（建玉未保有）であること

## 5. やってはいけないこと・安全対策

1. **`Generate` ボタンを押さない**:
   ブラウザで勝手に鍵を作ると、VPS上のシステムと連携できなくなります。必ず指定されたアドレスを貼り付けてください。
2. **秘密鍵を要求・送信しない**:
   今回の本番移行において、秘密鍵のやり取りは一切発生しません。マスターの秘密鍵を尋ねることも、システムの秘密鍵を外に出すこともありません。
3. **出金権限は遮断されている**:
   承認するエージェント鍵（`yowayowa-exec-main`）は、Hyperliquid のプロトコル仕様上「出金（withdraw）」「外部送金（usdSend）」の権限を持ちません。万一 VPS が侵害されても、マスターの資金を外部へ持ち出すことは原理的に不可能です。
