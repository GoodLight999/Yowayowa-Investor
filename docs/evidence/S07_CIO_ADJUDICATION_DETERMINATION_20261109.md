## 2. 正式裁定（U1〜U4の確定）

### U1: 窓端点の開閉

- **確定仕様**:
  $$\text{Window} = [2026-11-04\text{T}00:00:00.000\text{Z}, 2026-12-02\text{T}00:00:00.000\text{Z})$$
- **判定規則**:
  - イベント・約定時刻 $t$ に対し、$2026-11-04\text{T}00:00:00\text{Z} \le t < 2026-12-02\text{T}00:00:00\text{Z}$ を満たす取引のみを窓内実績として算入する。
  - $t < 2026-11-04\text{T}00:00:00\text{Z}$（例: 11-03取引）は厳格に窓外として除外する。
  - $t \ge 2026-12-02\text{T}00:00:00\text{Z}$（12-02T00:00:00.000Z ちょうどの約定を含む）は窓外とする。
- **根拠**:
  $end - start = 2,419,200 \text{秒} = 28.0 \text{日}$ であり、半開区間によって初めて UTC 11-04 〜 12-01 の正確に28回の日次標本・日次サイクルと整合する。両端閉区間は29日となり原典の「28日間」規定に違反する。

#### (3) ドローダウン計算式・ゼロフロア撤廃・資本制約

1. **ピーク及びドローダウン計算式**:
   標本系列 $E_i$（$i \in \{0, 1, \dots, N\}$、旧窓満了時は $N=28$）に対し：
   $$Peak_0 = E_0, \quad Peak_i = \max(Peak_{i-1}, E_i) = \max(E_0, E_1, \dots, E_i) \quad (i \ge 1)$$
   $$DD_i = \frac{Peak_i - E_i}{Peak_i} \ge 0$$
   $$MaxDD = \max_{0 \le i \le N} (DD_i) \times 100\%$$
   分母は各時点の累積実行ピーク $Peak_i > 0$ であり、固定値100ではない。
2. **ゼロフロアの完全撤廃**:
   旧実装の `max(0, (100 - E)/100)` は廃止。$E_i < Peak_i$ である限り、たとえ $E_i > E_0$（元本超過利益状態）であってもピークからの下落を漏れなく計上する。
3. **資本の不変性（Capital Invariant）**:
   窓期間中の外部入出金、手動資金振替、他戦略・他通貨からの流出入を厳格に禁止する。外部資金移動が検知された場合、DD計算は失効し公式判定は INCONCLUSIVE とする。
4. **受入テスト対照値**:
   受入試験 S07-A04 の合成系列 $[100, 120, 108]$ に対する MaxDD は **$10.0\%$**（$Peak=120$ 分母）である（起点分母12.0%、旧実装0.0%と明確に区別）。

### U3: 旧凍結窓（11-04〜12-02）の取扱い

- **確定方針**: **選択肢 (i) 停止のまま満了させ、公式判定を永続 INCONCLUSIVE として封印する。**
- **却下された対案**:
  選択肢 (ii)（修正実装を投入して残り23日間を継続）は**明確に却下**する。
- **決定理由**:
  1. **凍結前提の崩壊（体制断絶）**:
     前方凍結評価（Forward Frozen Evaluation）の存在意義は、「同一の戦略・同一の執行統制が、事前確定した窓内で均一に機能するか」を実証することにある。
     旧窓内5日間のうち3日（11-04, 11-05, 11-08）は、本来エントリー見送り（中立）であるべき局面でフォールバック強制SHORTが発動し、戦略自身のfunding遮断フィルタ（年率 −291.9%, −74.8%, −99.5%）を回避して発注していた。さらに手数料は推計式、統制ログはテンプレート固定値であった。
     これら5日間の汚染データの上に、修正された新実装の23日間を継ぎ足しても、得られる28日データは「前段5日は欠陥コード、後段23日は修正コード」という異質な混成物（Regime Break）に過ぎず、定量的な合否判定を下す統計的・規律的根拠になり得ない。
  2. **ゲート条件の現況と必然的結果**:
     11-08停止時点で、活動量は 5/8 往復（未達）、Net PnL は −0.156182 USDC（負）。停止のまま自然満了を迎えることで、条件①（8往復以上）未達による **INCONCLUSIVE** が確定する。
  3. **統制上の安全性**:
