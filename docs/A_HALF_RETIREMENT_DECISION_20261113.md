## 2. 留保（結論の限界 — 「否定」ではなく「示せなかった」）

1. **改善側の検証窓は 2021 年上昇相場が支配的。** Bonferroni 線を満たすには +0.370%/日 が必要で、この未使用730日では「示せなかった」。S-01 にエッジが存在しないことの証明ではない。
2. **結合側は n=44 で検出力が低い。** t=1.5 を出すには 0.46%/日（44日で約+22%）が必要。C4（t=-0.54）のように「有意な負」とは言えない仕様もある。言えるのは「G1不達」まで。ただし**全仕様の符号が負**なので合否（mean>0 要求）は検出力に依存しない。
3. **過去のバックテスト成績は遡って否定しない。** 2023-2026 の S-01（費用後 CAGR +21.85% 等、`docs/BACKTEST_REPORT_S01_CRYPTO_TREND.md`）は当時の記録として有効なまま保存する。今回否定したのは「凍結した物差しの下で、救済形が残らなかった」という前方・保持窓の判定である。
4. したがって本決定の根拠は **(i) 凍結物差しを越える形が残らなかったこと** と **(ii) 追試の機会費用が速度ドクトリンに反すること** の2点。エッジの不存在を主張するものではない。
