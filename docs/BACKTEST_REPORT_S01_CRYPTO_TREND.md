## 未検証の設計空間・限界

- 観測数で年率化するため、cash/warmupの日次0リターンも観測に残る。先頭200日はpre-windowデータがなく現金であり、warmup不足warningsは実際の履歴不足を示す。年率化CAGRは経過日数の実暦換算やリスクフリー調整Sharpeではない。
- 現金は無利息USDT。デペッグ、FX/USD換算、税、funding/borrow、custody、流動性制約、取引所停止、固定slippage超のmarket impactはモデル化しない。
- 固定BTC/ETHユニバースでありpoint-in-time構成でない。単一取引所・単一期間で、レジーム依存とselection/survivorship biasが残る。1資産発火時は100%集中する。
- dailyの価格ドリフト修正もコスト対象。短期の往復シグナル、コスト感度、実際の約定ずれにより収益は悪化し得る。
- IS/OOS開始日と観測数はlookbackごとに変わる。特に200日purgeはbaseline OOS序盤の下落を評価対象から外す。共通窓補助診断を示したが、複数窓rolling検証や独立forward評価ではない。
- IID bootstrapは自己相関・ボラクラスタリングを保持せず、短いOOSと多数の現金日がCIに影響する。全期間もOOSもゼロをまたぐ。将来予測区間ではない。
- 感度分析の最良値を後付け採用しない。200の最適性は証明されず、将来観測や別レジーム、共通OOS窓で再検証が必要。過去実績は将来を保証しない。
