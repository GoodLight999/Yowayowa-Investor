## 0. 結論（先に数値）

**素の S-01 の負けは、診断に基づく改善12本では G1 を越えられなかった。**

| 問い | 実測 |
|---|---|
| 事前登録12本のうち、多重性の線（Bonferroni t ≥ **2.8653**）に届いた本数 | **0本 / 12本** |
| 参考: G1 の素の線（t ≥ 1.5）に届いた本数 | **1本 / 12本**（P10 `atr_trail_2` t=1.559, 補正後 p=1.000） |
| 素の S-01 自身（BASE）の保持窓成績 | 純平均 **+0.1601%/日**・**t=1.239** → G1 不通過 |
| 改善が素の S-01 を上回ったか（保持窓・日次ペア差） | 12本すべて有意な改善なし（最良 P10 でも +0.0006%/日, t=0.007） |

## 6. 検出力と解釈（「示せなかった」と「否定した」を区別する）

- 保持窓の日次 sd = 3.4913%/日、n=730。平均の95%CI半幅 = **±0.2533%/日**。
- 多重性の線 t=2.8653 を満たすには **+0.3702%/日**（年率換算で極端に大きい）の純平均が必要。
- したがって本判定の意味は「**12本は G1 を越えるだけの縁を、この未使用730日では示せなかった**」であり、「改善が無効だと証明した」ではない。素の S-01 自身も同窓で t=1.239 と G1 不通過なので、この窓は素の戦略にも判定にも厳しい。
- レジーム差: 保持窓の損益は 2021 の上昇相場が支配（BASE 2021H1 +82.9%、2021H2 +34.4%、2022H1 -16.3%、2022H2 ±0.0%＝ゲートOFFで現金）。診断窓（2026年10〜11月の下落局面）とは局面が異なるため、**下落局面で効く仕様が上昇局面では露出を削って負ける**という方向のミスマッチが構造的に残る。

## 8. 限界・阻害要因

- **阻害要因による中断はない**（未使用データは730営業日確保でき、全12本を判定した）。
- ただし判定の完全性に関する限界は明示する:
  1. 未使用データは「2023年以降より前」の1区間しか存在しない（ストアの生データが 2023-01-01 開始のため）。将来側の未使用データは存在しない（2026-11-13 時点）。
  2. その1区間の損益は 2021 上昇相場が支配的で、診断窓（2026年10〜11月の下落）と局面が異なる。仕様の良し悪しを「下落局面での防御」で測れていない。
  3. 検出力は ±0.25%/日（95%CI）で、t≥2.87 には +0.37%/日 が必要。中程度の改善は原理的に検出できない。
  4. 診断所見のパラメータ（10%・2.0ATR 等）は診断窓から選んだ値であり、保持窓では out-of-sample。ただし仕様の「型」自体は診断窓を見て選んでいるため、型の選択には in-sample 性が残る（多重性の線はこの点を部分的にしか補正しない）。
  5. A の journal は1時間足の paper 約定で、評価器の next-open 日足モデルとは執行が異なる（診断窓で A -11.56% vs 複製 -12.08%）。診断の归属は journal 実測、判定は凍結エンジン仕様で行っており、両者を混ぜていない。
