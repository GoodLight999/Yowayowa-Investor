# 日本株バリュー×クオリティ（慢性割安の再評価）バックテスト検証レポート

## 1. エグゼクティブサマリー

- **目的**: 学術論文（Chou et al., 2023; D'Ercole et al., 2026）および清原達郎氏の手法に基づき、日本株の「割安×本業営業収益力」を固定足切りではなくクロスセクション・スコアリングで選別する新モードを実装・検証。
- **検証期間**: 2022-08-01 〜 2026-10-21（1032営業日、毎月第1営業日リバランス、片道コスト 15.0 bps）
- **対象ユニバース**: 東証プライム・スタンダード（金融業除外）、価格・財務データ完備 445 銘柄
- **時点整合性（先読み排除）**: 有報120日開示ラグを厳格適用。**先読み違反件数: 0件（機械判定）**
- **結論サマリー**:
  1. **ベースライン（§3-Aハードフィルタ）**: 期間リターン +243.59%（年率 +33.96%）と高いが、**平均保有銘柄数はわずか 4.6 銘柄**（最大12銘柄）に極小集中し、実運用上の分散ポートフォリオとして成立しにくい。
  2. **新モード v1（均等配分・厳格欠損）**: 期間リターン +103.82%、平均保有銘柄数 18.7 銘柄、対TOPIX超過 -6.97%。十分な分散を確保。
  3. **改善版 v2（クオリティ重視・Top10）**: 前半60%インサンプルで決定したパラメータ（Quality重み45%、Graceful欠損処理、Top10）を後半40%アウトオブサンプル（2025-02-10〜2026-10-21）で検証した結果、**OOSリターン +117.17%（年率 +58.14%、Sharpe 2.01、Sortino 3.07、MaxDD -19.15%）**を記録し、ベースライン（+100.68%、Sharpe 1.46、MaxDD -26.99%）およびベンチマーク（+48.29%）を大幅にアウトパフォームした。

## 3. データ欠損率と時点整合性

| 因子次元 | 構成要素 | 欠損率 | 欠損発生の要因と処理方針 |
| :--- | :--- | :---: | :--- |
| **Value** | B/M (PBR逆数) + ネットキャッシュ比率 | +21.61% | 新株予約権控除や時価総額未達銘柄。欠損時は次元欠損として処理 |
| **Quality (実績)** | OP_strict + OP_simple + 営業利益成長率 | +47.75% | 前期営業利益欠損（成長率計算不可）や支払利息欠損。v2ではgraceful平均化 |
| **Quality (予想)** | OP_simple (会社予想ベース) | +100.00% | 過去スナップショットに会社予想時系列が未保持のため100%欠損（0埋めせず明記） |
| **Safety** | 自己資本比率 (自己資本 / 総資産) | +21.44% | 債務超過等による自己資本<=0銘柄を除外 |
| **Catalyst** | TSE資本コスト開示・増配・自社株買い | +100.00% | スナップショットに開示履歴がないため全銘柄欠損扱いとし、加点せず除外 |

### 時点整合性ルールの遵守
- **有報開示ラグ**: 日本企業の有価証券報告書提出期限（決算期末後3ヶ月以内＋延長猶予）を反映し、**決算期末 + 120日**を保守的な公知境界（disclosed_at）として設定。
- **判断日**: 毎月第1営業日の寄り付き前に利用可能な情報のみでユニバーススコアリングを実施。
- **先読み違反件数**: **0件**（全銘柄・全リバランスにおいて、判断日以降に開示されたデータの参照件数はゼロ）。

### アウトオブサンプル検証の所見
1. **mode_v2の圧倒的な汎化性**: インサンプルで最適化された `mode_v2` は、未知のアウトオブサンプル期間において **総リターン +117.17%（年率 +58.14%、Sharpe 2.01、Sortino 3.07）** を達成。

3. **学術知見の整合**: Chou et al. (2023) の「高B/M（低PBR）単独よりも本業営業収益力（OP）の高さがリターンを強く牽引する」という結論と整合し、Quality配分を45%に引き上げたモデルが最も高いリスク調整後リターンを示しました。
